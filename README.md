## 📌 Опис проєкту

Даний репозиторій містить рішення .NET 8 з трьома взаємопов'язаними модулями для перевірки та тестування математичних функцій (Варіант 4) з автоматизацією збірки та тестування за допомогою **GitHub Actions CI/CD Pipeline**.

### 🧱 Структура рішення

1. **`ClassLibrary`** — бібліотека класів, що реалізує математичні функції та розрахунки згідно з Варіантом 4:
   - `LinearEquation` — лінійна функція $y = kx + b$, пошук кореня рівняння $kx + b = 0$.
   - `QuadraticEquation` — квадратична функція $y = ax^2 + bx + c$, обчислення дискримінанта та коренів.
   - `CubicEquation` — кубічна функція $y = ax^3 + bx^2 + cx + d$.
2. **`TestProject`** — проєкт модульних тестів на базі **xUnit** (варіант 4), що містить тестові сценарії (`[Fact]`, `[Theory]`, `[InlineData]`) для перевірки коректності обчислень та обробки вироджених випадків.
3. **`ConsoleApp`** — консольний клієнт, що демонструє виклик та практичне використання класів.

## ⚙️ CI/CD Конвеєр (GitHub Actions)

Конфігураційний файл `.github/workflows/dotnet.yml` налаштований на автоматичний запуск при кожному `push` або `pull_request` у гілки `master` та `main`.

### Етапи конвеєра:
1. **Checkout repository** — завантаження вихідного коду репозиторію на віртуальну машину `ubuntu-latest`.
2. **Setup .NET SDK** — розгортання робочого середовища `.NET SDK 8.0.x`.
3. **Restore dependencies** — відновлення NuGet-залежностей для рішення `PR6.sln`.
4. **Build solution** — компіляція проєкту у конфігурації `Release`.
5. **Run xUnit Tests** — автоматичний прогін усіх модульних тестів xUnit з генерацією детального логу та TRX-звіту.

---

## 🚀 Локальний запуск та тестування

Для відновлення залежностей, компіляції та запуску тестів локально виконайте у корені проєкту:

```bash
# Відновлення залежностей
dotnet restore PR6.sln

# Збірка проєкту
dotnet build PR6.sln --configuration Release

# Запуск модульних тестів xUnit
dotnet test PR6.sln --configuration Release --verbosity normal
```

## 📊 Результати тестування

Усі 10 модульних тестів успішно проходять верифікацію:
- `LinearEquationTests`: перевірка обчислення значення, пошук коренів та обробка паралельних прямих.
- `QuadraticEquationTests`: перевірка розрахунку дискримінанта, пошуку двох коренів, одного кореня, відсутності дійсних коренів та виродженого випадку $a = 0$.
